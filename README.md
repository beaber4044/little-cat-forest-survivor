# 🌿 고양이의 모험

작은 고양이의 커다란 숲 모험. 다가오는 몬스터를 물리치고
반짝이는 경험치를 모아 살아남는 생존 게임이에요.

- 이동만 하면 공격은 자동 (WASD / 방향키)
- 레벨업할 때마다 강화 선택
- 계정을 만들면 **전체 랭킹**에 기록이 올라가요

## 기술 구성

- 단일 HTML 파일 (이미지 인라인)
- 계정 · 랭킹 저장: [Supabase](https://supabase.com)
- 배포: GitHub Pages
